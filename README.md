# Use Moda Clara 👙✨

Catálogo online e loja virtual de moda praia com integração para pedidos via WhatsApp e painel administrativo integrado.

## 🚀 Funcionalidades

- **Catálogo de Produtos:** Visualização de biquínis, maiôs, saídas de praia e acessórios com fotos e detalhes.
- **Carrinho de Compras:** Adição de itens com seleção de tamanhos e cores.
- **Cálculo de Frete:** Consulta automática de CEP via ViaCEP e cálculo por região.
- **Checkout via WhatsApp:** Envio de pedido elegante e formatado diretamente para o WhatsApp da loja.
- **Painel Administrativo:** Gerenciamento fácil de produtos, categorias, dados e textos da loja.

## 📁 Estrutura do Projeto

O projeto é estruturado de forma modular e limpa para facilitar manutenção e customização:

```text
use-moda-clara/
├── index.html            # Estrutura HTML semântica da loja virtual
├── admin.html            # Estrutura HTML do painel administrativo
├── dados.js              # Base de dados de produtos, categorias e configurações
├── logo.png              # Logotipo oficial da Use Moda Clara
├── css/
│   ├── style.css         # Folha de estilos principal da loja (design responsivo)
│   └── admin.css         # Estilos específicos do painel administrativo
└── js/
    ├── app.js            # Lógica completa da loja (catálogo, rotas, carrinho, WhatsApp)
    └── admin.js          # Lógica do painel de administração (edição e exportação)
```
