# Use Moda Clara 👙✨

Catálogo online e loja virtual de moda praia com integração para pedidos via WhatsApp e painel administrativo integrado.

## 🚀 Funcionalidades

- **Catálogo de Produtos:** Visualização de biquínis, maiôs, saídas de praia e acessórios com fotos e detalhes.
- **Carrinho de Compras:** Adição de itens com seleção de tamanhos e cores.
- **Cálculo de Frete:** Cálculo e seleção de opções de envio por região/CEP.
- **Checkout via WhatsApp:** Envio formatado de todo o pedido com dados do cliente e entrega diretamente para o WhatsApp da loja.
- **Painel Administrativo (`admin.html`):** Gerenciamento e edição de produtos e configurações locais.

## 📁 Estrutura de Arquivos

- `index.html`: Página principal da loja e catálogo para os clientes.
- `admin.html`: Painel administrativo de controle de catálogo.
- `dados.js`: Base de dados inicial dos produtos e configurações da loja.
- `logo.png`: Identidade visual da marca.

## 🌐 Como Publicar (GitHub Pages)

Você pode publicar este site gratuitamente usando o **GitHub Pages**:

1. Acesse o repositório no GitHub.
2. Vá em **Settings** > **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Clique em **Save**. Em alguns minutos o site estará disponível online!
